# Blade Shift : 차원 베기 러너

> 장애물은 피하고, 적은 베어 넘기며, 막힌 길은 베어 여는 슬래시 러닝 액션

Python과 pico2d로 개발하는 2D 횡스크롤 스피드 슬래시 러닝 액션 게임입니다.
피하기만 하는 기존 러닝 게임에 베는 손맛을 더해, 달리는 내내 공격적으로 길을 여는 경험을 목표로 합니다.

**현재 상태: 필수 범위와 추가 기능(보스전과 차원 절단, 탄막 마법사와 패링, Phase 3, 타격감 연출, 사운드) 구현 완료**

## 플레이 흐름

**달린다 → 피한다 → 벤다 → 돌파한다 → 바뀐다**

1. 캐릭터가 자동으로 계속 전진합니다.
2. 점프와 슬라이딩으로 장애물을 피합니다.
3. 적을 베어 점수를 얻습니다.
4. 장벽 앞을 지키는 보스를 쓰러뜨려 봉인을 풀고 거대 장벽을 벱니다.
5. 점수가 오르면 맵 페이즈가 바뀝니다.

HP는 3칸이며, HP가 0이 되거나 추락하면 게임 오버입니다.

## 실행 방법

```powershell
pip install pico2d
python main.py
```

## 조작법

| 입력 | 동작 |
|---|---|
| `W` | 점프, 공중에서 2단 점프 |
| `S` | 슬라이딩 |
| `Space` | 일섬 대시 |
| 좌클릭 | 기본 베기, 탄막 패링 |
| 불릿 타임 중 좌+우 동시 클릭 | 차원 절단 |
| `A`, `D` | 보스전에서 좌우 이동 |
| `ESC` | 일시 정지 |

## 핵심 재미 요소

### 일섬 연쇄

낭떠러지 위의 공중 몬스터를 일섬 대시로 베고 공중 점프로 이어 건너갑니다.
일섬은 최대 2회까지 쌓이고 4초마다 1회씩 충전됩니다.
적을 처치해도 돌려받지 않습니다.

### 페이즈 시프트

일정 점수에 도달하면 맵 배경과 중력, 속도가 바뀝니다.

| 페이즈 | 진입 점수 | 변화 |
|---|---|---|
| Phase 1 · 무너지는 고성 | 시작 | 기본 중력, 기본 속도 |
| Phase 2 · 무중력 균열 | 3,000점 | 중력 50%, 공중 일섬 연쇄 구간 |
| Phase 3 · 폭주하는 심연 | 8,000점 | 속도 1.5배, 점수 배율 2배 |

### 차원 절단

거대 장벽은 봉인되어 있습니다. 장벽 앞을 지키는 보스를 쓰러뜨려 봉인을 풀면, 불릿 타임 중 좌우 동시 클릭으로 장벽을 두 동강 냅니다.

- **등장:** 달린 시간 약 30초마다 보스와 장벽이 함께 나옵니다. 보스전 시간은 세지 않습니다.
- **보스전:** 보스와 마주하면 카메라가 멈추고, `A`, `D`로 좌우로 움직이며 싸웁니다. 페이즈마다 다른 보스를 둘 예정이며, 지금은 모든 페이즈에 `봉인의 수문장`이 나옵니다.
- **봉인의 수문장:** HP 36이고 베기는 1, 일섬은 3의 피해를 줍니다. 기본 공격인 바닥 내려찍기는 점프하거나 뒤로 물러나 피합니다. 처치하면 500점을 얻습니다.
- **입력:** 두 버튼을 0.15초 이내에 누르면 동시 클릭입니다. 불릿 타임 중에는 기본 베기가 나가지 않습니다.
- **불릿 타임:** 0.2배속으로 최대 3초 지속됩니다. 이 동안 적의 공격과 탄막이 멈추고, 플레이어는 장벽 외의 피해를 받지 않습니다.
- **연출:** 동시 클릭하면 1.6초 동안 플레이어 주변으로 힘이 모이고, 마지막에 터지며 장벽이 잘립니다. 이후 0.9초 동안 느린 화면에서 원래 속도로 돌아옵니다.
- **성공:** 장벽이 파괴되고 500점을 얻습니다.
- **실패:** 불릿 타임 안에 입력하지 못하면 HP가 1칸 줄고 장벽이 파괴됩니다.

## 개발 일정

| 주차 | 목표 | 필수 구현 |
|---|---|---|
| 1주차 | 이동, 맵 | 달리기, 점프, 슬라이딩, 무한 맵과 장애물, 타이틀 화면 |
| 2주차 | 전투, 생존 | 베기 공격, 몬스터 2종(근접병, 사역마), HP, 게임 오버 |
| 3주차 | 핵심 기믹 | 일섬 대시, 일섬 연쇄 구간 |
| 4주차 | 페이즈, 그래픽 | Phase 1~2 맵 변환, 캐릭터와 몬스터 그래픽 |
| 5주차 | 마무리 | 타이틀, 게임, 결과 화면 연결, 점수와 최고 기록, 밸런싱, 버그 수정 |
