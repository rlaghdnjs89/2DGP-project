# Blade Shift : 차원 베기 러너

> 장애물은 피하고, 적은 베어 넘기며, 막힌 길은 베어 여는 슬래시 러닝 액션

Python과 pico2d로 개발하는 2D 횡스크롤 스피드 슬래시 러닝 액션 게임입니다.
피하기만 하는 기존 러닝 게임에 베는 손맛을 더해, 달리는 내내 공격적으로 길을 여는 경험을 목표로 합니다.

**현재 상태: 구조 개편 기획안 v2(`블레이드 시프트 — 구조 개편 기획안 v2.pdf`) 구현 중. 규칙이 다르면 v2를 따른다.**

## 플레이 흐름

**달린다 → 원석에 닿는다 → 보스를 넘는다 → 장벽을 벤다 → 다음 스테이지**

한 번의 도전(런)은 스테이지 3개로 이루어집니다.

1. **달리기:** 약 90초 동안 자동으로 전진하며 점프, 슬라이딩, 베기, 일섬으로 나아갑니다. 남은 거리는 상단 진행 막대로 보여 줍니다.
2. **진화의 원석:** 적과 장애물이 없는 안전 구역입니다. 화면이 멈추고 HP가 모두 회복되며, `도전` 버튼을 누르면 3초 뒤 달려 나갑니다.
3. **보스 아레나:** 카메라가 고정되고 `A`, `D`로 좌우로 움직이며 싸웁니다.
4. **돌파:** 보스를 쓰러뜨리면 장벽의 봉인이 풀리고, 차원 절단으로 장벽을 벱니다.
5. **전환:** 차원 관문을 지나 다음 스테이지로 넘어갑니다. 스테이지 3 보스를 쓰러뜨리면 클리어입니다.

HP는 3칸이며, HP가 0이 되거나 추락하면 스테이지 1부터 다시 시작합니다.

## 실행 방법

```powershell
pip install pico2d
python main.py
```

## 조작법

| 입력 | 동작 |
|---|---|
| `W` | 점프, 공중에서 2단 점프 |
| `S` | 슬라이딩 |
| `Space` | 일섬 대시 |
| 좌클릭 | 기본 베기, 탄막 패링 |
| 불릿 타임 중 좌+우 동시 클릭 | 차원 절단 |
| `A`, `D` | 보스전에서 좌우 이동 |
| `ESC` | 일시 정지 |

## 핵심 재미 요소

### 일섬 연쇄

낭떠러지 위의 공중 몬스터를 일섬 대시로 베고 공중 점프로 이어 건너갑니다.
일섬은 최대 2회까지 쌓이고 4초마다 1회씩 충전됩니다.
적을 처치해도 돌려받지 않습니다.

### 스테이지

보스를 쓰러뜨리면 맵 배경과 중력, 속도가 바뀝니다.

| 스테이지 | 물리 | 달리기 청크 |
|---|---|---|
| 1 · 무너지는 고성 | 기본 중력, 속도 ×1.0 | A, B, C, D, G |
| 2 · 무중력 균열 | 중력 50%, 속도 ×1.0 | E-1~3 |
| 3 · 폭주하는 심연 | 기본 중력, 속도 ×1.5 | A, B, C, D, D, G |

### 차원 절단

거대 장벽은 봉인되어 있습니다. 장벽 앞을 지키는 보스를 쓰러뜨려 봉인을 풀면, 불릿 타임 중 좌우 동시 클릭으로 장벽을 두 동강 냅니다.

- **등장:** 보스와 장벽은 스테이지 끝에만 나옵니다. 스테이지 3에는 장벽이 없고, 보스를 쓰러뜨리면 바로 클리어입니다.
- **보스전:** 보스와 마주하면 카메라가 멈추고, `A`, `D`로 좌우로 움직이며 싸웁니다. 스테이지마다 다른 보스를 둘 예정이며, 지금은 모든 스테이지에 `봉인의 수문장`이 나옵니다.
- **봉인의 수문장:** HP 36이고 베기는 1, 일섬은 3의 피해를 줍니다. 기본 공격인 바닥 내려찍기는 점프하거나 뒤로 물러나 피합니다.
- **입력:** 두 버튼을 0.15초 이내에 누르면 동시 클릭입니다. 불릿 타임 중에는 기본 베기가 나가지 않습니다.
- **불릿 타임:** 0.2배속으로 최대 3초 지속됩니다. 이 동안 적의 공격과 탄막이 멈추고, 플레이어는 장벽 외의 피해를 받지 않습니다.
- **연출:** 동시 클릭하면 1.6초 동안 플레이어 주변으로 힘이 모이고, 마지막에 터지며 장벽이 잘립니다. 이후 0.9초 동안 느린 화면에서 원래 속도로 돌아옵니다.
- **성공:** 장벽이 파괴됩니다.
- **실패:** 불릿 타임 안에 입력하지 못하면 HP가 1칸 줄고 장벽이 파괴됩니다.

## 개발 일정

| 주차 | 목표 | 필수 구현 |
|---|---|---|
| 1주차 | 이동, 맵 | 달리기, 점프, 슬라이딩, 무한 맵과 장애물, 타이틀 화면 |
| 2주차 | 전투, 생존 | 베기 공격, 몬스터 2종(근접병, 사역마), HP, 게임 오버 |
| 3주차 | 핵심 기믹 | 일섬 대시, 일섬 연쇄 구간 |
| 4주차 | 페이즈, 그래픽 | Phase 1~2 맵 변환, 캐릭터와 몬스터 그래픽 |
| 5주차 | 마무리 | 타이틀, 게임, 결과 화면 연결, 점수와 최고 기록, 밸런싱, 버그 수정 |

일정에 여유가 생기면 차원 절단, 탄막 마법사와 패링, Phase 3, 타격감 연출, 사운드를 추가합니다.
