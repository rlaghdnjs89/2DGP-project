# Blade Shift : 차원 베기 러너

> 장애물은 피하고, 적은 베어 넘기며, 막힌 길은 베어 여는 슬래시 러닝 액션

Python과 pico2d로 개발하는 2D 횡스크롤 스피드 슬래시 러닝 액션 게임입니다.
피하기만 하는 기존 러닝 게임에 베는 손맛을 더해, 달리는 내내 공격적으로 길을 여는 경험을 목표로 합니다.

**현재 상태: 기획 단계 (1차 발표 준비 중)**

| 항목 | 내용 |
|---|---|
| 개발자 | 김로안 (2023184006) |
| 수업 | 2D 게임 프로그래밍 |
| 개발 환경 | Python, pico2d |
| 개발 기간 | 5주 (1인 개발) |
| 플레이 인원 | 1인 싱글 플레이 |
| 게임 목표 | 최대한 멀리 달려 최고 점수 갱신 |

## 플레이 흐름

**달린다 → 피한다 → 벤다 → 돌파한다 → 바뀐다**

1. 캐릭터가 자동으로 계속 전진합니다.
2. 점프와 슬라이딩으로 장애물을 피합니다.
3. 적을 베어 점수와 발도술 게이지를 얻습니다.
4. 모은 게이지로 거대 장벽을 벱니다.
5. 점수가 오르면 맵 페이즈가 바뀝니다.

HP는 3칸이며, HP가 0이 되거나 추락하면 게임 오버입니다.

## 조작법

| 입력 | 동작 |
|---|---|
| `W` | 점프, 공중에서 2단 점프 |
| `S` | 슬라이딩 |
| `Space` | 일섬 대시 |
| 좌클릭 | 기본 베기, 탄막 패링 |
| 좌+우 동시 클릭 | 차원 절단 |
| `ESC` | 일시 정지 |

## 핵심 재미 요소

### 일섬 연쇄

낭떠러지 위의 공중 몬스터를 일섬 대시로 연속해서 베며 건너갑니다.
일섬으로 적을 처치하면 쿨타임이 즉시 초기화되어 다음 적으로 이어 갈 수 있습니다.

### 페이즈 시프트

일정 점수에 도달하면 맵 배경과 중력, 속도가 바뀝니다.

| 페이즈 | 진입 점수 | 변화 |
|---|---|---|
| Phase 1 · 무너지는 고성 | 시작 | 기본 중력, 기본 속도 |
| Phase 2 · 무중력 균열 | 3,000점 | 중력 50%, 공중 일섬 연쇄 구간 |
| Phase 3 · 폭주하는 심연 | 8,000점 | 속도 1.5배, 점수 배율 2배 |

### 차원 절단

적을 베어 게이지를 100%까지 채우면, 불릿 타임 중 좌우 동시 클릭으로 거대 장벽을 두 동강 냅니다.

## 개발 일정

| 주차 | 목표 | 필수 구현 |
|---|---|---|
| 1주차 | 이동, 맵 | 달리기, 점프, 슬라이딩, 무한 맵과 장애물, 타이틀 화면 |
| 2주차 | 전투, 생존 | 베기 공격, 몬스터 2종(근접병, 사역마), HP, 게임 오버 |
| 3주차 | 핵심 기믹 | 일섬 대시, 일섬 연쇄 구간 |
| 4주차 | 페이즈, 그래픽 | Phase 1~2 맵 변환, 캐릭터와 몬스터 그래픽 |
| 5주차 | 마무리 | 타이틀, 게임, 결과 화면 연결, 점수와 최고 기록, 밸런싱, 버그 수정 |

일정에 여유가 생기면 차원 절단, 탄막 마법사와 패링, Phase 3, 타격감 연출, 사운드를 추가합니다.
